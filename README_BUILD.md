# Генератор заявочников — сборка и запуск

## Что нового в этой версии

1. **Путь к `Настройки.xlsx` больше не зашит в коде.** Программа сама ищет
   файл в таком порядке: место, запомненное с прошлого раза → папка самой
   программы → Рабочий стол/Документы/Загрузки → корни всех дисков (на
   Windows). Если нигде не находит — один раз спросит через окошко "Открыть
   файл" и запомнит выбор. Чтобы заставить программу спросить заново
   (например, если файл настроек переехал), нажмите в интерфейсе кнопку
   **«Изменить файл настроек…»**.

2. **Можно выбрать, что именно генерировать.** При запуске открывается окно
   со списком всех комбинаций «категория товара — сеть» из листа «Задания».
   Отметьте галочками нужные (или нажмите «Выбрать всё» для сразу всех) и
   нажмите «Сгенерировать выбранное». Сам файл настроек при этом не
   меняется — колонка «Генерировать (Да/Нет)» в нём используется только как
   исходное состояние галочек.

3. **Полноценный интерфейс** — окно с журналом хода генерации, кнопкой
   «Открыть папку с заявочниками» и понятными сообщениями об ошибках.

4. **Своя иконка** — `icon/zaevochnik.ico`, уже подключена и к окну
   программы, и к exe-файлу при сборке.

Программу по-прежнему можно запустить без окна флагом `--console` — тогда
она, как раньше, соберёт всё, что отмечено «Да» на листе «Задания». Это
полезно для автоматического запуска по расписанию (Планировщик заданий
Windows), когда нажимать кнопки некому.

## Структура проекта

```
run_zaevochnik.py              — точка входа (GUI по умолчанию, --console — без окна)
requirements.txt
build_exe.bat                  — сборка в .exe одной командой (Windows)
icon/zaevochnik.ico             — иконка программы
zaevochnik_engine/
    settings_locator.py         — поиск и запоминание пути к Настройки.xlsx
    config_loader.py            — чтение листов файла настроек
    pipeline.py                 — сборка одного заявочника (координатор шагов)
    gui/
        app.py                   — окно программы (Tkinter)
    data/
        reader.py, filterer.py, column_selector.py
    excel/
        writer.py, formulas.py, table_style.py,
        top_header.py, data_validation.py, layout.py
```

## Запуск без сборки в exe (для разработки/проверки)

Нужен установленный Python 3.9+ для Windows (в него уже встроен `tkinter`,
отдельно ставить не нужно).

```bat
pip install -r requirements.txt
python run_zaevochnik.py
```

## Сборка в .exe

Так конечным пользователям не нужно будет ставить Python вообще — просто
двойной клик по файлу.

1. Установите Python 3.9+ (на компьютере, где собираете exe — на компьютерах
   пользователей Python не понадобится).
2. Откройте папку проекта и запустите `build_exe.bat` двойным кликом (или
   `build_exe.bat` из командной строки).
3. Дождитесь надписи «Готово!». Готовый файл появится здесь:
   `dist\Генератор заявочников.exe`
4. Скопируйте этот один файл куда нужно (например, на Рабочий стол
   пользователя). Больше ничего копировать не нужно — все зависимости уже
   внутри exe.

Если нужно собрать вручную (без .bat-файла), команда та же, что внутри
`build_exe.bat`:

```bat
pip install pyinstaller pandas openpyxl
pyinstaller --noconfirm --onefile --windowed --name "Генератор заявочников" --icon "icon\zaevochnik.ico" --add-data "icon;icon" run_zaevochnik.py
```

### Важные примечания

- **`--windowed`** убирает чёрное окно консоли — программа откроется сразу
  как обычное Windows-приложение. Если вам вместо этого нужен exe для
  запуска по расписанию флагом `--console` (с выводом в лог/консоль),
  соберите второй exe той же командой, но без `--windowed`.
- **Антивирус может ругаться на новый exe** — это стандартное поведение для
  файлов, собранных PyInstaller (Windows/антивирусы не знают такого
  «издателя»). Это ложное срабатывание; при желании exe можно подписать
  сертификатом кода, чтобы это прошло.
- Первый обычный (не `--onefile`) вариант сборки собирается и запускается
  немного быстрее, но вместо одного exe даёт целую папку файлов. Если
  важна скорость запуска больше, чем «один файл для копирования», замените
  `--onefile` на `--onedir` в команде выше.
- Программа хранит запомненный путь к `Настройки.xlsx` в
  `%APPDATA%\Zaevochnik\settings_location.json` — при переустановке или
  переносе на новый компьютер этот файл создастся заново при первом
  запуске.
